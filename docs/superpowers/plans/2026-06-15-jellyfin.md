# Jellyfin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Jellyfin media server (serving `/Users/apple/work/videos`) to the `local-infra` Docker Compose stack and wire it into Prometheus, Grafana, and blackbox like every other service.

**Architecture:** One `jellyfin` container (official upstream image) on the `local-infra` bridge, media bind-mounted read-only; a `jellyfin-exporter` sidecar that polls Jellyfin's API and exposes Prometheus metrics; a Prometheus scrape job plus a blackbox probe for the public domain; and the upstream `rebelcore/jellyfin_grafana` dashboard provisioned via the existing file provider.

**Tech Stack:** Docker Compose, `jellyfin/jellyfin`, `rebelcore/jellyfin-exporter`, Prometheus, blackbox-exporter, Grafana (file provisioning).

**Spec:** `docs/superpowers/specs/2026-06-15-jellyfin-design.md`

**Note on TDD:** This is configuration, not application code. Each task's "test" is a config-validation gate (compose parse, promtool, JSON validity) run *before* committing. Runtime verification that needs Jellyfin's interactive first-run wizard is collected in the final task and is performed by the user.

### Task 1: Add Jellyfin + exporter services to Compose

**Files:**
- Modify: `docker-compose.yml` (services block, after the `cadvisor` service near line 354; and the `volumes:` block near line 384)

- [ ] **Step 1: Add the `jellyfin` and `jellyfin-exporter` services**

In `docker-compose.yml`, immediately after the `cadvisor` service block (before the `networks:` block), add:

```yaml
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: jellyfin
    restart: unless-stopped
    ports:
      - "8096:8096"
    environment:
      TZ: ${TZ:-Asia/Shanghai}
      JELLYFIN_PublishedServerUrl: https://jellyfin.sprite3366.com
    volumes:
      - jellyfin_config:/config
      - jellyfin_cache:/cache
      - /Users/apple/work/videos:/media:ro
    networks:
      - local-infra

  jellyfin-exporter:
    image: rebelcore/jellyfin-exporter:latest
    container_name: jellyfin_exporter
    restart: unless-stopped
    command:
      - "--jellyfin.address=http://jellyfin:8096"
      - "--jellyfin.token=${JELLYFIN_TOKEN}"
    ports:
      - "9594:9594"
    depends_on:
      - jellyfin
    networks:
      - local-infra
```

- [ ] **Step 2: Add the two named volumes**

In the `volumes:` block at the bottom of `docker-compose.yml` (after `portainer_data:`), add:

```yaml
  jellyfin_config:
    driver: local
  jellyfin_cache:
    driver: local
```

- [ ] **Step 3: Validate the Compose file parses**

Run: `docker compose config -q`
Expected: exits 0, no output. (A `warning: variable JELLYFIN_TOKEN not set` style message is acceptable — it is supplied in `.env` in Task 4.)

- [ ] **Step 4: Confirm the new services resolve as expected**

Run: `docker compose config | grep -E 'jellyfin|9594|8096|/media'`
Expected: shows the `jellyfin` and `jellyfin-exporter` services, the `8096:8096` and `9594:9594` port mappings, and the `/Users/apple/work/videos:/media:ro` bind mount.

- [ ] **Step 5: Commit**

```bash
git add docker-compose.yml
git commit -m "Add Jellyfin and jellyfin-exporter services"
```

### Task 3: Provision the Grafana dashboard

**Files:**
- Create: `grafana/provisioning/dashboards/json/jellyfin-overview.json`

The upstream `rebelcore/jellyfin_grafana` dashboard needs no transformation: it has no `__inputs`/`DS_PROMETHEUS` import placeholders, and its panels reference `{ "type": "prometheus" }` with no uid, which Grafana resolves to the default datasource. The repo's Prometheus datasource is `isDefault: true` (`grafana/provisioning/datasources/datasources.yml`), so it renders correctly under file provisioning. We only normalize its `uid` for naming consistency with `kafka-overview` / `etcd-overview`.

- [ ] **Step 1: Download and normalize the dashboard**

Run (from the repo root):

```bash
curl -fsSL https://raw.githubusercontent.com/rebelcore/jellyfin_grafana/master/dashboards/jellyfin.json \
  | python3 -c 'import sys,json; d=json.load(sys.stdin); d["uid"]="jellyfin-overview"; d["id"]=None; json.dump(d, sys.stdout, indent=2)' \
  > grafana/provisioning/dashboards/json/jellyfin-overview.json
```

- [ ] **Step 2: Verify it is valid JSON with the expected uid and metrics**

Run:

```bash
python3 -c "import json;d=json.load(open('grafana/provisioning/dashboards/json/jellyfin-overview.json'));print('uid:',d['uid'],'title:',d['title'])"
grep -c 'jellyfin_media_count\|jellyfin_up\|jellyfin_transcoding_sessions' grafana/provisioning/dashboards/json/jellyfin-overview.json
```

Expected: `uid: jellyfin-overview title: Jellyfin` and a non-zero match count.

- [ ] **Step 3: Commit**

```bash
git add grafana/provisioning/dashboards/json/jellyfin-overview.json
git commit -m "Provision Jellyfin Grafana dashboard"
```

### Task 4: Bring-up & verification (requires the user — Jellyfin's first-run wizard cannot be automated)

**Files:** `.env` (gitignored — not committed)

- [ ] **Step 1: Start Jellyfin**

Run: `docker compose up -d jellyfin`
Expected: container `jellyfin` is `Up`. Confirm: `docker compose ps jellyfin`.

- [ ] **Step 2: Run the setup wizard**

Open `http://localhost:8096`, create the admin user, and add a library whose folder is `/media` (it contains `animation`, `drama`, `movie`).

- [ ] **Step 3: Create an API key**

In Jellyfin: Administration → Dashboard → API Keys → "+" → create a key. Copy it.

- [ ] **Step 4: Put the key in `.env`**

Add to `.env` (create the line if absent):

```
JELLYFIN_TOKEN=<paste the API key>
```

(Optional: also add `TZ=Asia/Shanghai` if you want to override the default.)

- [ ] **Step 5: Start the exporter and verify metrics**

```bash
docker compose up -d jellyfin-exporter
sleep 5
curl -s http://localhost:9594/metrics | grep -E '^jellyfin_(up|media_count|user_active)'
```

Expected: lines such as `jellyfin_up 1` and `jellyfin_media_count{...} N`. If `jellyfin_up 0`, the token is wrong — re-check Step 4 and `docker compose up -d jellyfin-exporter` again.

- [ ] **Step 6: Reload Prometheus and confirm the targets**

```bash
docker compose up -d prometheus
curl -s -X POST http://localhost:9090/-/reload
```

Then open `http://localhost:9090/targets` and confirm `jellyfin_exporter` is **UP** and the `blackbox` job lists `https://jellyfin.sprite3366.com`.

- [ ] **Step 7: Confirm the Grafana dashboard**

```bash
docker compose up -d grafana
```

Open Grafana (`http://localhost:3002`) → Dashboards → "Jellyfin". Confirm panels show data (not "No data" / "datasource not found").

- [ ] **Step 8: Point the public domain at Jellyfin**

In your external reverse proxy / tunnel (where `grafana.sprite3366.com` etc. are configured — not in this repo), route `jellyfin.sprite3366.com` → host `:8096`. Verify `https://jellyfin.sprite3366.com` loads and that the blackbox target turns green in Prometheus.
